# Writer Prompts

AI-assisted prompts for manuscript writing.

## Available Prompts

- `abstract.md` - Generate abstract from manuscript content
- `improve_clarity.md` - Improve writing clarity and flow
- `reviewer_response.md` - Generate response to reviewer comments

## Usage

These prompts can be used with AI assistants to help with:
- Drafting and refining manuscript sections
- Ensuring consistency across the document
- Responding to peer review feedback
