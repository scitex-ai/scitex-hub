# Console Prompts

AI-assisted prompts for code analysis and execution.

## Available Prompts

- `code_review.md` - Review code for issues
- `documentation.md` - Generate code documentation
- `analysis_template.md` - Create analysis scripts

## Usage

These prompts can be used with AI assistants to help with:
- Writing reproducible analysis code
- Debugging and optimization
- Creating well-documented scripts
