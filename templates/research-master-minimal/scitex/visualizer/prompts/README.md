# Visualizer Prompts

AI-assisted prompts for figure creation and data visualization.

## Available Prompts

- `figure_description.md` - Generate figure captions
- `visualization_suggestion.md` - Suggest appropriate visualizations
- `style_consistency.md` - Ensure consistent figure styling

## Usage

These prompts can be used with AI assistants to help with:
- Creating publication-quality figures
- Choosing appropriate chart types
- Writing descriptive figure captions
