How to Create a New Module

  1. Create the app: apps/your_app/ with __init__.py, apps.py, views.py, urls.py
  2. Add templates: templates/your_app/index.html (extends global_base.html) and index_partial.html (standalone partial for AJAX)
  3. Create a context builder: build_your_context(request, current_project=None)
  4. Register in registry.py: Add a ModuleConfig(...) entry to _BUILTIN_MODULES
  5. Add URL pattern: path("your/", include(("apps.your_app.urls", "your_app"))) in config/urls.py
  6. Add inline tests: Use ModuleTestMixin in tests.py

File Structure
