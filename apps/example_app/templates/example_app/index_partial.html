Python 

def build_ctx(
    request,
    project=None
):
    return {
        "project": project,
        "data": [...],
    }

def index_view(request):
    proj = get_project(
        request)
    ctx = build_ctx(
        request, proj)
    return render(
        request,
        "app/index.html",
        ctx)

Plugin Rules

Contract for Workspace Modules

  • MUST have index.html that extends global_base.html
  • MUST have index_partial.html as a standalone AJAX partial
  • MUST register a ModuleConfig entry in registry.py
  • MUST provide build_<name>_context(request, current_project)
  • MUST scope all CSS under a unique top-level class (e.g. .your-workspace)
  • MUST use --workspace-* CSS variables — no hardcoded colors
  • MUST NOT exceed 512 lines per file (PY / TS / CSS) or 1024 lines (HTML)
  • MUST NOT implement business logic in Django — delegate to scitex package
  • MUST NOT use silent fallbacks — raise and surface errors clearly
  • MUST NOT hardcode model names, URLs, or dynamic lists
