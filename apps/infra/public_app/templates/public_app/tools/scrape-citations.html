How to Use

  1. Drag the button above to your bookmarks bar
  2. Open Asta AI and search for papers (get citations)
  3. Click the bookmark to start scraping
  4. Watch the live progress notification (counter + ETA)
  5. Done! Citations auto-download as .bib file and copy to clipboard

How It Works

  • Scans the page for all "Copy BibTeX" buttons
  • Fast Mode: Tries to extract BibTeX directly from DOM (instant)
  • Fallback Mode: If DOM scraping fails, clicks buttons sequentially
  • Shows live notification with counter, progress bar, and ETA
  • Collects all BibTeX data and combines with proper formatting
  • Automatically downloads as .bib file with timestamp
  • Copies to clipboard as backup
