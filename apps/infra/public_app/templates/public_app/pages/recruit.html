オープンソース・コントリビューター（学生歓迎・随時）

GitHub 上で公開している SciTeX の開発に参加していただける方を募集しています。 経験の有無は問いません。はじめての方向けの Issue を用意しています。

  • 参加方法: GitHub の good first issue から着手し、Pull Request を送る
  • 使用技術: Python / PyTorch / Django / TypeScript / Docker・Apptainer / LLM API
  • ライセンス: AGPL-3.0（CLA へのご同意をお願いしています）

参加すると得られるもの

  • 研究者かつ開発者からの技術指導 — コードレビューと設計の議論を通じて、 研究とソフトウェア開発の両方の作法をお伝えします。
  • 公開された実績 — 貢献は GitHub にあなたの名前で残り、そのまま実績として示せます。
  • 実際に使われるものを作る経験 — 研究者が日々使うソフトウェアです。

Build the tools that speed up science

SciTeX develops and operates an open-source automation ecosystem for scientific research. Everything we build is public, and anyone can take part.

Open-source contributors (students welcome, rolling)

We welcome contributors to SciTeX on GitHub. No prior experience required — we keep a set of good first issue tickets for newcomers.

  • How to start: pick a good first issue and open a pull request
  • Stack: Python / PyTorch / Django / TypeScript / Docker & Apptainer / LLM APIs
  • License: AGPL-3.0 (we ask contributors to sign a CLA)

What you get

  • Mentorship from a researcher-developer — code review and design discussion covering both research practice and software engineering.
  • A public track record — your contributions stay under your own name on GitHub and travel with you.
  • Real users — this is software scientists actually use, not a practice exercise.

Coming next

  • University-partnered internships (for academic credit) — in discussion with universities in Shizuoka, Japan.
  • Paid positions — as the business grows.
