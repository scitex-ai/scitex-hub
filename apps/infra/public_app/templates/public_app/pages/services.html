料金について

研究では「なぜこの手法か」を説明します。私たちも、価格の考え方を できるだけ透明にしたいと考えています（内訳を細かく約束するものではありません）。

ストレージ・保管について

主にストレージの維持・バックアップ・監視・運営にかかるコストを反映しています。 利益の最大化ではなく、継続して運営するための価格です。

計算（Compute）について

ローカルでの計算は無料です。SciTeX Cloud を使う場合のみ、 実際に使った計算資源に応じてご負担いただきます。

LLM（生成AI）の利用料について

ご自身の API 契約を使う場合、SciTeX からの上乗せは0円です。 お支払いを代行する場合も、実費と管理の実費のみをいただきます。

料金の考え方

  • 自分で用意できるものは、無料で使えるようにします。
  • 囲い込み（ロックイン）を目的にした価格設定はしません。
  • API の利用料は、できるかぎり実費にします。
  • 継続して運営できる価格を目指します。
  • 値上げする場合は、その理由を公開します。
