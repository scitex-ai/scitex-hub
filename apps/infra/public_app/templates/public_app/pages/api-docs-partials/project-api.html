Project: File Operations

Manage files in your project repository.

GET /{user}/{slug}/api/file-tree/ Get project file tree
POST /{user}/{slug}/api/files/upload/ Upload file
POST /{user}/{slug}/api/files/create/ Create new file
DELETE /{user}/{slug}/api/files/delete/ Delete file

Example: Upload File

curl -X POST "https://scitex.ai/jane/my-project/api/files/upload/" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@figure1.png" \
  -F "path=figures/"

Project: Git Operations

Full git operations for your project repository.

GET /{user}/{slug}/api/git/status/ Repository status
POST /{user}/{slug}/api/git/stage/ Stage file for commit
POST /{user}/{slug}/api/git/commit/ Create commit
GET /{user}/{slug}/api/git/history/ Commit history
