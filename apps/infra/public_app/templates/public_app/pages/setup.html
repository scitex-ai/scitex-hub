{% trans "Self-Hosting Guide" %}

{% trans "Run your own SciTeX Hub on a workstation, a lab server or a cloud VM." %}

{% trans "What You Get" %}

{% trans "One Docker Compose stack serves the same apps as scitex.ai:" %}

  • Scholar — {% trans "literature search, BibTeX libraries and citation networks." %}
  • Writer — {% trans "LaTeX manuscripts with live PDF preview." %}
  • FigRecipe — {% trans "reproducible, editable scientific figures." %}
  • Files / Storage — {% trans "project files backed by Gitea repositories, plus storage browsing." %}
  • Cards — {% trans "a task board shared by people and agents." %}
  • Agents — {% trans "persistent per-project AI agents." %}
  • Chat — {% trans "an AI assistant through LiteLLM. Each user brings their own provider key (BYOK), so the server needs no LLM key." %}

{% trans "Cards, Storage and Agents appear only when their packages (scitex-cards, scitex-storage, scitex-agent-container) are installed in the Django image." %}

{% trans "Architecture" %}

  • django — {% trans "web app, REST API and WebSockets (port 8000)" %}
  • postgres — PostgreSQL 15
  • redis — {% trans "Redis 7 for cache and the Celery broker" %}
  • celery_worker / celery_beat — {% trans "background and scheduled jobs" %}
  • gitea — {% trans "Git server that stores every project" %}
  • umami — {% trans "self-hosted, cookie-free analytics" %}

{% trans "Production adds pgbouncer, nginx, autoheal and an optional cloudflared tunnel. Compose files live in deployment/docker/docker_dev/ and deployment/docker/docker_prod/." %}

{% trans "Requirements" %}

  • {% trans "Linux (Windows via WSL2)" %}
  • {% trans "Docker Engine with the Compose v2 plugin (deployment/docker/common/install_docker.sh installs both)" %}
  • {% trans "Git and GNU Make" %}
  • {% trans "8 GB RAM or more recommended" %}
  • {% trans "No host Python or Node.js needed: the images ship Python 3.11 and Node.js 20" %}

{% trans "Quick Start" %}

{% trans "Every Make target needs an explicit ENV (dev, staging or prod)." %}

git clone https://github.com/scitex-ai/scitex-hub.git
cd scitex-hub
cp deployment/docker/envs/.env.example deployment/docker/envs/.env.dev
# edit .env.dev: replace every CHANGE_ME value
make ENV=dev start
make status

{% trans "Open http://localhost:8000. The first start runs migrations and creates test-user; its password is printed in the Django log unless you set SCITEX_HUB_TEST_USER_PASSWORD." %} 

make ENV=dev logs-web
make ENV=dev createsuperuser

{% trans "Production" %}

  1. {% trans "Create deployment/docker/envs/.env.prod from the same template and set:" %} 
    SCITEX_HUB_DJANGO_SETTINGS_MODULE=config.settings.settings_prod
DEBUG=False
SCITEX_HUB_SITE_URL=https://hub.example.org
SCITEX_HUB_ALLOWED_HOSTS=hub.example.org
SCITEX_HUB_ENABLE_SSL_REDIRECT=true
  2. {% trans "Prepare the host. make ENV=prod start checks the service user and SLURM before it starts anything." %} 
    sudo deployment/host-setup/scripts/create-scitex-user.sh
make ENV=prod start
make ENV=prod verify-health

{% trans "Configuration" %}

{% trans "All settings come from the env file. The template deployment/docker/envs/.env.example lists everything; these matter most. Never commit a filled-in env file." %}

{% trans "Variable" %} {% trans "Purpose" %}
SCITEX_HUB_DJANGO_SECRET_KEY {% trans "Django secret. Generate a fresh random value per deployment." %}
SCITEX_HUB_DJANGO_SETTINGS_MODULE config.settings.settings_dev / settings_prod
SCITEX_HUB_SITE_URL {% trans "Public URL. Its host also becomes the site domain used in links and e-mails." %}
SCITEX_HUB_ALLOWED_HOSTS {% trans "Comma-separated host names Django accepts." %}
SCITEX_HUB_POSTGRES_DB, _USER, _PASSWORD {% trans "PostgreSQL credentials, used by Django, Gitea and Umami." %}
SCITEX_HUB_REDIS_URL {% trans "Redis for cache and Celery." %}
SCITEX_HUB_GITEA_ADMIN_USERNAME, _PASSWORD {% trans "Gitea admin account. Regenerate the API token with make ENV=<env> gitea-token." %}
SCITEX_HUB_EMAIL_HOST, _PORT, _HOST_USER, _HOST_PASSWORD {% trans "SMTP for sign-up, password reset and notifications." %}
SCITEX_HUB_HEALTH_NOTIFICATION_RECIPIENT {% trans "Where site-down alerts go. Unset means nobody is alerted." %}
SCITEX_HUB_GOOGLE_CLIENT_ID, SCITEX_HUB_ORCID_CLIENT_ID {% trans "Optional Google and ORCID sign-in (with their client secrets)." %}

{% trans "Optional Services" %}

  • Stripe — {% trans "set SCITEX_HUB_STRIPE_SECRET_KEY and SCITEX_HUB_STRIPE_WEBHOOK_SECRET to enable paid plans. Without them the hub runs normally; card setup and subscriptions stay disabled." %}
  • Cloudflare Tunnel — {% trans "publish the hub without opening ports: set SCITEX_HUB_CLOUDFLARE_TUNNEL_TOKEN_PROD for the cloudflared service. See deployment/docs/09_CLOUDFLARE_TUNNEL.md." %}
  • SLURM — {% trans "runs browser terminals and compute jobs in Apptainer containers. See deployment/slurm/README.md." %} 
    make slurm-status
make apptainer-build
  • Agents — {% trans "point SCITEX_AGENT_CONTAINER_API_URL at the host's sac listen and mount its token file with SCITEX_AGENT_CONTAINER_API_TOKEN_FILE_HOST." %}
  • {% trans "Local paper databases" %} — {% trans "CrossRef Local and OpenAlex Local for offline search, via CROSSREF_LOCAL_API_URL and OPENALEX_LOCAL_API_URL." %}

{% trans "Adding Apps" %}

{% trans "Apps are Python packages. Any installed package that declares a scitex.apps entry point is added to Django, mounted under /apps/<name>/ and listed in the launcher, with no hub code changes. Add the package to the Django image and rebuild. App authors start with the scitex-app SDK:" %}

pip install scitex-app[cli]
scitex-app app --help

{% trans "Upgrading" %}

{% trans "rebuild builds new images while the old stack keeps serving, checks the new image, then swaps containers. restart does not pick up new code." %}

git pull
make ENV=prod rebuild
make ENV=prod migrate

{% trans "Backups" %}

{% trans "db-backup writes a timestamped pg_dump to deployment/backups/ (create the directory first). Also back up the Gitea volume, the user data directory (/opt/scitex/data/users in production, data/users/ in dev) and your env file." %}

make ENV=prod db-backup
make ENV=prod db-shell

{% trans "Troubleshooting" %}

  • {% trans "Start with make status, make ENV=<env> ps and make ENV=<env> logs-error." %}
  • {% trans "password authentication failed: the env file still uses old SCITEX_CLOUD_* names; rename them to SCITEX_HUB_*." %}
  • {% trans "Links or e-mails show the wrong domain: fix SCITEX_HUB_SITE_URL and restart." %}
  • {% trans "Code changes not visible: run rebuild, not restart." %}
  • {% trans "Port conflicts between environments: make stop-all, then start one." %}
  • {% trans "Production start refused: run deployment/host-setup/scripts/create-scitex-user.sh and fix what check-slurm.sh reports." %}
