Marketplace Submission Terms

Last updated: February 2026

1. Submission Requirements

By submitting an app to the SciTeX Marketplace, you agree to the following:

  • Your app does not contain malicious code, backdoors, or security vulnerabilities.
  • Your app includes a valid LICENSE file with a recognized open-source license (AGPL-3.0, MIT, Apache-2.0, or BSD-3-Clause).
  • Your app includes a README.md with a clear description of its functionality.
  • Your app passes the automated validation checks (structure, security scan).
  • You have the right to distribute the code under the chosen license.

2. Code of Conduct

App authors must adhere to the following standards:

  • No harmful content: Apps must not contain hate speech, harassment, or content that promotes violence.
  • No data exfiltration: Apps must not collect, transmit, or store user data without explicit consent and clear documentation.
  • No resource abuse: Apps must not intentionally consume excessive CPU, memory, or network resources.
  • Transparency: Apps must clearly document what they do, including any external API calls or network activity.
  • Respect for users: Apps must not interfere with other installed modules or degrade the user experience.

3. Review Process

All submissions are reviewed by the SciTeX team before publication:

  • Automated security scanning for dangerous patterns.
  • Manual review of code structure and functionality.
  • Validation of license compliance.
  • Review typically completes within 3-5 business days.

Submissions may be rejected with feedback. Authors may address issues and resubmit.

4. Takedown Policy

SciTeX reserves the right to remove any published app for the following reasons:

  • Security vulnerability discovered after publication.
  • Violation of these terms or the code of conduct.
  • Valid DMCA or intellectual property complaint.
  • App becomes abandoned and poses a security risk.

Authors will be notified via email before takedown when possible, with an opportunity to address the issue.

5. Licensing

See SciTeX App Maker License Exception for details on the three-tier licensing model. Apps using the SciTeX workspace API are not derivative works of the AGPL-licensed core.

6. Changes to Terms

These terms may be updated from time to time. Continued use of the marketplace after changes constitutes acceptance of the updated terms.
