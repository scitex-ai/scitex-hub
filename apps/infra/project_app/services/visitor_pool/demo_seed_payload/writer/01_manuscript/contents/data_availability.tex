\section*{Data and Code Availability}
\pdfbookmark[1]{Data and Code Availability}{data-availability}

All data and code used in this example are contained in the project itself; no
download or network access is required.

\begin{itemize}
  \item \textbf{Data:} \texttt{data/digits\_sample.csv} --- 500 labelled
    $8\times8$ digit images. Provenance, licence, and the exact subset
    selection are documented in \texttt{data/README.md}. The source corpus is
    the UCI \emph{Optical Recognition of Handwritten Digits} dataset
    (Alpaydin \& Kaynak, 1998), redistributed with scikit-learn under
    BSD-3-Clause.
  \item \textbf{Code:} \texttt{scripts/reproduce\_figures.py} --- regenerates
    \texttt{figures/digit\_grid.png}, \texttt{figures/confusion\_matrix.png},
    the JPEGs this manuscript compiles, and the accuracy quoted in Section
    \ref{sec:results}. All random draws are seeded.
\end{itemize}
