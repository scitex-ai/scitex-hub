SciTeX App Maker License Exception

Three-Tier Licensing

SciTeX uses a layered licensing model that maximizes openness while protecting user freedom:

Tier 1 Core Platform — AGPL-3.0

The SciTeX Cloud platform, workspace framework, and all built-in modules are licensed under the GNU Affero General Public License v3.0.

  • Ensures the platform remains open source
  • Modifications to the core must be shared
  • Network use triggers copyleft obligations

Tier 2 App Maker SDK — Apache-2.0

The SciTeX workspace API interfaces, module registration protocol, and template contracts are provided under the Apache License 2.0.

  • Apps using the SDK API are not derivative works of the AGPL core
  • Compatible with proprietary and open-source licenses
  • Patent grant included

Tier 3 User Apps — Author's Choice

Apps published on the SciTeX Apps catalog may use any license the author chooses, including proprietary licenses.

  • Supported: AGPL-3.0, MIT, Apache-2.0, BSD-3-Clause
  • License must be declared in the project's LICENSE file
  • License badge displayed on apps catalog listing

What This Means for App Developers

If your app only uses the SciTeX workspace API (registering modules, rendering templates, using the file tree, calling MCP tools), it is not a derivative work of the AGPL-licensed core. You are free to license your app however you wish.

If your app modifies or incorporates SciTeX core code (not just calling its APIs), then AGPL obligations apply to those modifications.
