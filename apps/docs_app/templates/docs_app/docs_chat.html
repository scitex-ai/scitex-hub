AI Chat

Multi-session AI chat with MCP tool integration, voice input, and shareable conversations.

Chat Sessions

Chat sessions are stored server-side and persist across browser reloads. Each session has a UUID (shown as tooltip on the session chip) and a user-editable title.

Action Behavior
New chat Creates a new session (C1, C2…)
Click session chip Switches to that session, loads message history
Double-click chip Inline rename the session title
Hover chip Tooltip shows session UUID (share token)
Right-click chip Context menu: Share / Rename / Delete
on chip Delete the session (visible on hover)

Auto-Creation

If no sessions exist, C1 is automatically created on page load. The last active session is restored from sessionStorage.

Conversation Sharing

Chat sessions can be shared as read-only public URLs. No authentication is required to view a shared conversation.

How to Share

There are two ways to share a conversation:

  • Share button () — in the sessions bar, toggles sharing for the current session
  • Right-click → Share — context menu on any session chip

When sharing is enabled, the share URL is automatically copied to clipboard.

Share URL Format

https://<host>/llm/shared/<uuid>/

Security Model

Property Detail
Access control UUID token — unguessable, no auth required
Permissions Read-only — no editing, no input
Opt-in is_shared must be explicitly enabled; URL returns 404 when sharing is off
Revocation Toggle share off → URL immediately returns 404
Shared indicator icon on session chip when shared

Shared View

The read-only page displays the session title, owner username, date, and all messages rendered as chat bubbles. No input controls are shown.

Features

Feature Description
LLM Model Selection Choose from configured providers via gear menu
MCP Tool Integration AI can use SciTeX tools (stats, plots, scholar, etc.)
Voice Input Microphone button with STT model selection and volume visualizer
Image Attachment Camera capture, file upload, or sketch pad
Markdown Rendering Code blocks, tables, lists, inline formatting
Copy / Print Export entire conversation as text or print

API Endpoints

Endpoint Method Description
/llm/api/sessions/ GET List all sessions for current user
/llm/api/sessions/ POST Create a new session
/llm/api/sessions/<id>/ PATCH Update title or is_shared
/llm/api/sessions/<id>/ DELETE Delete a session
/llm/api/sessions/<id>/messages/ GET Get all messages in a session
/llm/api/sessions/<id>/messages/add/ POST Add a message to a session
/llm/shared/<uuid>/ GET Read-only shared view (no auth)
/llm/api/shared/<uuid>/ GET Shared session JSON (no auth)
