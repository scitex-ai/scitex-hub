Agent Integration

AI coding agents (Claude, Codex, Gemini) work inside SciTeX terminals with shared MCP tools and synchronized configuration.

Supported Agents

Three AI coding agents are supported out of the box. All are installed automatically on first terminal login.

Agent npm Package Command
Claude Code @anthropic-ai/claude-code claude
OpenAI Codex @openai/codex codex
Google Gemini @google/gemini-cli gemini

Agent Sources

Agents are installed as global npm packages inside the Apptainer container. Installation happens automatically on first login via .bashrc.

Installation Path 
~/.nvm/                   # Node Version Manager (v0.40.1)
~/.npm-global/            # npm global prefix
  bin/
    claude                # @anthropic-ai/claude-code
    codex                 # @openai/codex
    gemini                # @google/gemini-cli
    agents                # agents CLI (ywatanabe1989/agents fork)
Auto-Install Mechanism

On first login, .bashrc checks if claude is available. If not:

  1. Installs nvm + Node.js 20 LTS
  2. Sets npm global prefix to ~/.npm-global
  3. Runs npm install -g for all four packages
  4. Creates ~/.ai-cli-installed sentinel

Subsequent logins skip installation entirely.

Agent Configs

The agents CLI (fork of amtiYo/agents) synchronizes MCP server configuration across all AI coding tools from a single source of truth.

Project Config Files (auto-generated) 
<project>/
  .agents/
    agents.json     # Single source of truth (schema v3)
    local.json      # Secrets (gitignored)
    skills/         # Synced to .claude/skills/, .cursor/skills/, etc.
    commands/       # Synced to .claude/commands/ (Claude Code only)
    hooks/          # Synced to .claude/hooks/ (Claude Code only)
  AGENTS.md         # Unified instructions for all AI tools
  .mcp.json         # Claude Code MCP server (direct fallback)
agents.json (Schema v3) 
{
  "schemaVersion": 3,
  "instructions": {"path": "AGENTS.md"},
  "integrations": {
    "enabled": ["claude", "codex", "gemini", "cursor", "copilot_vscode"]
  },
  "mcp": {
    "servers": {
      "scitex": {
        "label": "SciTeX Platform",
        "description": "145+ MCP tools",
        "transport": "stdio",
        "command": "/usr/local/bin/scitex",
        "args": ["mcp", "start"]
      }
    }
  }
}
Synchronization

On every login, .bashrc runs agents sync --quiet which propagates agents.json to each tool's native config format:

  • Claude Code → .mcp.json
  • Codex → its own config
  • Gemini → its own config
  • Skills → .claude/skills/, .cursor/skills/, .gemini/skills/, .windsurf/skills/
  • Commands → .claude/commands/ (Claude Code only)
  • Hooks → .claude/hooks/ (Claude Code only)

This means you configure MCP tools once in agents.json and all three agents see the same 145+ tools.
