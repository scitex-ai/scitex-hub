Marketplace

The Marketplace is a catalog of all workspace modules. Users can browse, install, star, review, and reorder modules.

Feature Description
Install / Uninstall Add or remove modules from your tab bar
Enable / Disable Toggle module visibility (built-ins cannot be uninstalled, only disabled)
Reorder Drag to reorder tab positions (syncs across tab bar and marketplace)
Star Bookmark favorite modules
Review Rate (1–5) and comment on modules
Publish Submit user modules for public listing (requires admin review)

Built-in modules are auto-seeded into the marketplace on first visit. Categories: writing, visualization, data, analysis, reference, utility.

User Modules (App Maker)

The App Maker lets authenticated users create custom modules from Python source code directly in the browser.

Field Description
slug Unique identifier per user
label Display name
source_code Python source (validated for security)
icon FontAwesome icon class
category writing, visualization, data, analysis, reference, utility
visibility private, group (shared with project), public
version Semantic version string
dependencies JSON list of required packages

API endpoints:

Endpoint Method Description
/appmaker/api/create/ POST Create a new module
/appmaker/api/<slug>/update/ POST Update module source and metadata
/appmaker/api/<slug>/run/ POST Execute module (sandboxed)
/appmaker/api/<slug>/delete/ POST Soft-delete module
User-submitted source code is scanned for forbidden patterns (os.system, subprocess, eval, exec, open, etc.) before execution.
