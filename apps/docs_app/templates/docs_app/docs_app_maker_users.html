Apps Catalog

The Apps catalog lists all available workspace modules. You can browse, install, and manage modules from here.

Feature Description
Install / Uninstall Add or remove modules from your tab bar
Enable / Disable Toggle module visibility (built-ins cannot be uninstalled, only disabled)
Reorder Drag to reorder tab positions (syncs across tab bar and apps catalog)
Star Bookmark favorite modules
Review Rate (1–5) and comment on modules

Built-in modules are auto-seeded into the catalog on first visit. Categories: writing, visualization, data, analysis, reference, utility.

Dev Install from Hub

Any app repo in Hub Explore can be installed as a personal dev app in your workspace — no approval required.

Step Action
1. Browse Go to Hub Explore and find repos with the App badge
2. Install Click “Dev Install” on any app repo
3. Use The app appears as a tab in your workspace (only visible to you)
4. Uninstall Go to Apps → My Dev Apps → click Uninstall
Dev-installed apps are live — they always reflect the latest code from the source repo. Changes by the app creator are immediately visible.

Browser Editor (App Maker)

The App Maker lets authenticated users create custom modules from Python source code directly in the browser — no CLI or git required.

Field Description
slug Unique identifier per user
label Display name in the tab bar
source_code Python source (validated for security)
icon FontAwesome icon class
category writing, visualization, data, analysis, reference, utility
visibility private, group (shared with project), public
version Semantic version string
dependencies JSON list of required packages
User-submitted source code is scanned for forbidden patterns (os.system, subprocess, eval, exec, open, etc.) before execution.

App Maker API

Endpoint Method Description
/appmaker/api/create/ POST Create a new module
/appmaker/api/<slug>/update/ POST Update module source and metadata
/appmaker/api/<slug>/run/ POST Execute module (sandboxed)
/appmaker/api/<slug>/delete/ POST Soft-delete module

Publishing Your App

There are two tiers of app distribution:

Tier Scope Approval
Dev Install Personal — only you see the tab None (instant)
Apps Catalog Public — all users can install Staff review via PR to scitex/apps

To publish to the public catalog:

  1. Create your app (via App Maker or CLI scaffold)
  2. Test it thoroughly in your workspace
  3. Run scitex-cloud app submit . — this opens a PR on the scitex/apps registry
  4. Staff reviews and merges the PR
  5. The app appears in the public Apps Catalog
For more advanced apps with custom templates, Platform Services, and Gitea integration, see the Creators guide.
