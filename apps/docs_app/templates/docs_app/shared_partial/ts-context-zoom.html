Context Zoom

Intercepts Ctrl+Wheel and Ctrl++/-/0 to apply per-pane zoom (font size or CSS scale) based on which pane the mouse is over, with localStorage persistence.

Import 

import {
  initContextZoom,
  registerZoomZone,
  getActiveZone,
  ZoomZone,
} from '@shared/components/context-zoom';

Initialization 

// Call once at app startup — sets up global Ctrl+Wheel listener
initContextZoom();

Register a Zoom Zone 

const editorPane = document.getElementById('my-editor-pane')!;

registerZoomZone({
  el: editorPane,
  storageKey: 'my-app.editor.fontSize',
  min: 10,
  max: 32,
  default: 14,
  step: 1,
  getSize: () => parseFloat(editorPane.style.fontSize) || 14,
  setSize: (val) => { editorPane.style.fontSize = `${val}px`; },
});

// For CSS zoom (scale) instead of font size
registerZoomZone({
  el: previewPane,
  storageKey: 'my-app.preview.zoom',
  min: 0.5,
  max: 3.0,
  default: 1.0,
  step: 0.05,
  getSize: () => parseFloat(previewPane.style.zoom) || 1,
  setSize: (val) => { previewPane.style.zoom = String(val); },
});

// Passthrough: pane handles zoom internally, just block browser zoom
registerZoomZone({
  el: monacoPane,
  storageKey: 'my-app.monaco.zoom',
  min: 0, max: 0, default: 0,
  passthrough: true,
  getSize: () => 0,
  setSize: () => {},
});

ZoomZone Interface

Field Type Description
el HTMLElement The DOM element defining the zoom zone boundary
storageKey string localStorage key for persisting zoom level
min number Minimum zoom value
max number Maximum zoom value
default number Reset value (Ctrl+0)
step number Increment per scroll tick (default: 1)
getSize () => number Reads current zoom value from the element
setSize (val: number) => void Applies new zoom value to the element
passthrough boolean If true, only blocks browser zoom; element handles zoom itself (e.g. Monaco)
Saved zoom values are restored from localStorage on registerZoomZone(). Call initContextZoom() once before registering zones. Zones use mouseenter/mouseleave to track the active zone.
