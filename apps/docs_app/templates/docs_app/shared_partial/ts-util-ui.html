UI Utilities

Common UI helpers: toast notifications, status messages, loading states, modals, and timing utilities.

Import 

import { showToast, showStatus, setButtonLoading, showSpinner,
Modal, confirm, debounce, throttle } from '@shared/utils/ui';

Usage 

// Toast notification (auto-dismissed after 5 s)
showToast('File saved.', 'success');
showToast('Something went wrong.', 'error', 8000);

// Status inside a container element
showStatus('Uploading…', 'info', 'status-container');

// Button loading state
const btn = document.getElementById('submit-btn')!;
setButtonLoading(btn, true, 'Saving…');
await apiClient.post('/api/save/', data);
setButtonLoading(btn, false);

// Spinner inside a container
showSpinner('content-area', true);
showSpinner('content-area', false);

// Bootstrap modal wrapper
const modal = new Modal('my-modal');
modal.show(); modal.hide(); modal.toggle();

// Debounce / throttle
const onSearch = debounce((q: string) => doSearch(q), 300);
const onScroll = throttle(() => updateHeader(), 100);

API Reference

Function / Class Signature Description
showToast() (message, type?, duration?) → void Fixed-position Bootstrap alert at top-right. type: success | error | warning | info. Default duration 5000 ms; pass 0 to keep indefinitely.
showStatus() (message, type, containerId?) → void Inserts an alert into a specific container (or document.body). Replaces any existing alert in that container. Auto-removed after 5 s.
setButtonLoading() (button, isLoading, loadingText?) → void Disables the button and shows a spinner + text while loading; restores original HTML when isLoading is false.
showSpinner() (containerId, show?) → void Appends or removes a Bootstrap .spinner-border inside the element identified by containerId.
Modal new Modal(elementId) Wraps a Bootstrap modal (or plain display: flex/none fallback). Methods: .show(), .hide(), .toggle().
confirm() (message) → Promise<boolean> Async wrapper around window.confirm(). Returns true if the user clicked OK.
debounce() (fn, wait) → fn Returns a debounced function that delays invoking fn until after wait ms of inactivity.
throttle() (fn, limit) → fn Returns a throttled function that fires at most once per limit ms regardless of call rate.
