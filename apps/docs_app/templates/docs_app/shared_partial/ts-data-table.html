DataTable

A full spreadsheet-like table with cell selection, keyboard navigation, Excel-compatible copy/paste, fill handle, column resizing, and virtual scrolling for large datasets.

Import 

import { DataTableManager, Dataset, DataRow, DataTableConfig } from '@shared/components/data-table';

HTML 

<!-- Minimal container — the component renders all internals -->
<div class="data-table-container" id="my-table"></div>

TypeScript Usage 

// Basic setup
const table = new DataTableManager({
  container: '#my-table',
  onDataChange: (data: Dataset) => console.log(data),
  onStatusUpdate: (msg: string) => updateStatusBar(msg),
});

// Start blank
table.initializeBlankTable();
table.renderEditableDataTable();
table.setupColumnResizing();

// Or load from CSV string
table.loadFromCSVContent(csvString, 'results.csv');
table.renderEditableDataTable();

// Read-only mode
const viewer = new DataTableManager({
  container: '#my-viewer',
  readOnly: true,
  initialData: { columns: ['A', 'B'], rows: [{ A: 1, B: 2 }] },
});

DataTableConfig

Option Type Default Description
container string | HTMLElement required CSS selector or element where the table renders
readOnly boolean false Disables all editing interactions
initialData Dataset — Pre-load data on construction
onDataChange (data: Dataset) => void — Fired on every cell edit
onStatusUpdate (msg: string) => void — Status bar message callback
virtualScrolling boolean true Enable virtual scrolling for large tables
maxDisplayRows number — Row count threshold before virtual scrolling activates

Key Types

Type Shape Description
Dataset { columns: string[], rows: DataRow[] } Full table data structure
DataRow { [key: string]: string | number } One row keyed by column name
Keyboard shortcuts: Arrow keys navigate, F2 or double-click to edit, Ctrl+C/Ctrl+V for Excel-compatible clipboard, Delete to clear selection. Maximum 32767 rows and 32767 columns.
