Selector Nav

A vertical icon-and-label navigation strip used for app switching, mode selection, or any vertical sidebar nav.

Import 

/* CSS is auto-loaded globally — no import needed. */
/* Manage active state in TypeScript: */
items.forEach(i => i.classList.remove('active'));
clickedItem.classList.add('active');

  </a>

CSS Classes & Attributes

Name Type Description
.selector-nav class Container: vertical flex column, dark background, scrollable
.selector-nav-item class Each nav item: icon above label, 8px vertical padding, hover and active states
.selector-nav-label class Text label below the icon (9px, uppercase letter-spacing)
.active modifier on item Highlights the item with primary icon color and active indicator
data-indicator="right" attribute on nav Shows the active indicator bar on the right edge instead of left (default)
Active state management (toggling .active) is your responsibility. The component provides only styling. Use <a> tags for navigation and <button> tags for in-page mode switching.
