Overview

SciTeX workspace modules are self-contained apps that appear as tabs in the workspace. Each module gets its own URL, AJAX-loaded partial, keyboard shortcut, and LLM skill integration.

There are four ways to add modules:

Method For Status
Built-in Core modules (Writer, Scholar, Vis, Hub, Console, Tools) Stable
CLI Scaffold + Upload Full apps with manifest, Platform Services, and Gitea sync New
App Maker (Web Editor) Quick Python modules via browser editor WIP
External Package pip-installable modules discovered via entry points WIP

Documentation by Audience

Choose the guide that matches your role:

For Users

Browse the Apps Catalog, install/uninstall modules, reorder tabs, star and review apps, or create quick modules with the App Maker browser editor.

For Creators (Developers)

Architecture, CLI scaffold, Platform Services, manifest schema, ModuleConfig, templates, context builders, LLM skills, CSS theming, testing, and publishing workflow.

For Administrators

External package management, review queue, moderation checklist, and approval workflow for public app submissions.

Quick Start

Goal Command / Action
Install an app Visit Apps Catalog and click Install
Create via browser Visit App Maker and write Python code
Create via CLI scitex-cloud app init . --name my_app
Upload to workspace scitex-cloud workspace upload --name my-app
Validate structure scitex-cloud app validate .
Publish to catalog scitex-cloud app publish .
