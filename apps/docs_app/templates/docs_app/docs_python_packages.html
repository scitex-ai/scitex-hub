Installation

Main package (includes all sub-modules) 
pip install scitex
Standalone packages 
pip install figrecipe          # Publication-ready figures
pip install scitex-writer      # LaTeX manuscript compilation
pip install scitex-dataset     # Scientific dataset search
pip install scitex-linter      # Coding style linter
pip install crossref-local     # Local CrossRef database
pip install openalex-local     # Local OpenAlex database
