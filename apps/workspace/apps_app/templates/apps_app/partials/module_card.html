The fallback used to jump straight from the runtime registry to `module_name`, which is the SLUG — so the public App Store rendered "writer", "scholar", "figrecipe", "clew" in lowercase for every card whose registry entry was not resolved. Measured on production 2026-08-16; the operator screenshots this page. AppsModule.label exists for exactly this ("Human-readable display name (manifest.json 'label')") and IS populated — Writer, Scholar, FigRecipe, Console — it was simply never consulted. config/branding.py states the same contract for tab titles: "Capitalization here is the contract: 'Cards', never 'cards'". Slug remains the last resort, so an app with no label at all still renders something rather than an empty heading. {% endcomment %}
