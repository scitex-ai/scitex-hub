Icon Color System

Icons use a warm yellowish color scheme that adapts between light and dark modes.

Light Mode
rgb(184, 164, 130) Default
rgb(204, 184, 150) Hover/Active 
.nav-icon-fa {
  color: rgb(184, 164, 130);
  opacity: 0.85;
}

.header-nav-item:hover .nav-icon-fa {
  color: rgb(204, 184, 150);
  opacity: 1;

CSS Filters (for IMG icons)

Applied to .nav-icon class for image-based icons

/* Default state */
.nav-icon {
  filter: brightness(1) saturate(1)
          sepia(0.5) hue-rotate(10deg)
          opacity(0.85);
}

/* Hover/Active state */
.header-nav-item:hover .nav-icon {
  filter: brightness(1.1) saturate(1.2)
          sepia(0.6) hue-rotate(15deg)
          opacity(1);
}

Best Practices

  • ✓ Use FontAwesome for consistency - All navigation icons use FontAwesome 6.0.0 for visual consistency
  • ✓ Apply proper CSS classes - Use .nav-icon-fa for FontAwesome icons, .nav-icon-svg for SVG icons
  • ✓ Maintain alignment - Ensure icons and text are vertically centered using flexbox
  • ✓ Use standard sizes - Navigation icons should be 16px (font-size) or 20px (container height)
  • ✗ Don't mix icon systems - Avoid mixing FontAwesome, SVG, and image icons in the same navigation
  • ✗ Don't hardcode colors - Use CSS classes and variables instead of inline styles

/* Navigation Icons - Enhanced with warm orange/yellowish colors */
.nav-icon,
.nav-icon-svg,
.nav-icon-fa {
  height: 20px;
  width: 20px;
  min-width: 20px;
  opacity: 0.85;
  transition: opacity 0.2s ease, transform 0.2s ease,
              filter 0.2s ease, color 0.2s ease;
  display: flex;
  align-items: center;
  justify-content: center;
  flex-shrink: 0;
  line-height: 1;
}

/* SVG icons with currentColor */
.nav-icon-svg {
  color: rgb(184, 164, 130); /* Warm yellowish */
  opacity: 0.85;
}

/* FontAwesome icons in light mode - yellowish */
.nav-icon-fa {
  color: rgb(184, 164, 130); /* Warm yellowish */
  opacity: 0.85;
}

/* IMG icons in light mode - apply warm orange/yellowish filter */
.nav-icon {
  filter: brightness(1) saturate(1) sepia(0.5)
          hue-rotate(10deg) opacity(0.85);
}

/* Header nav item alignment */
.header-nav-item {
  color: var(--scitex-color-01);
  padding: 8px 12px;
  border-radius: 6px;
  transition: background 0.2s ease;
  font-size: 14px;
  font-weight: 400;
  white-space: nowrap;
  display: flex;
  align-items: center;
  gap: 8px;
  text-decoration: none;
  min-width: fit-content;
  line-height: 1;
}

.header-nav-item .nav-label {
  line-height: 20px; /* Match icon height for perfect alignment */
  display: flex;
  align-items: center;
}

/* Light mode hover/active for IMG icons - brighter orange/golden */
.header-nav-item:hover .nav-icon,
.header-nav-item.active .nav-icon {
  filter: brightness(1.1) saturate(1.2) sepia(0.6)
          hue-rotate(15deg) opacity(1);
  transform: scale(1.05);
}

/* Light mode hover/active for SVG and FA icons */
.header-nav-item:hover .nav-icon-svg,
.header-nav-item.active .nav-icon-svg,
.header-nav-item:hover .nav-icon-fa,
.header-nav-item.active .nav-icon-fa {
  color: rgb(204, 184, 150); /* Brighter yellowish on hover/active */
  opacity: 1;
}

/* Dark mode */
[data-theme="dark"] .nav-icon {
  filter: brightness(1.1) saturate(1) sepia(0.4)
          hue-rotate(10deg) opacity(0.9);
}

[data-theme="dark"] .header-nav-item:hover .nav-icon,
[data-theme="dark"] .header-nav-item.active .nav-icon {
  filter: brightness(1.3) saturate(1.2) sepia(0.5)
          hue-rotate(15deg) opacity(1);
}
