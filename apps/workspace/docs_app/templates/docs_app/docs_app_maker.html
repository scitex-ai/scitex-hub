What is App Maker?

App Maker is SciTeX Cloud's opt-in plugin system. You create self-contained web apps that plug into the workspace as tabs — alongside the terminal, file browser, AI chat, and every other tool. Apps are installed, uninstalled, and modified without touching the platform core.

Think of it like browser extensions, but for a scientific research environment. Each app gets its own URL, templates, styles, data storage, and AI integration — all wired up automatically by the scaffold.

Why Build on SciTeX?

Tailored to Your Project

Every research project has unique requirements — custom data views, specialized analysis tools, domain-specific workflows. Mass-market products can't address these needs well. App Maker lets you build exactly what your project needs as a first-class workspace tab, fully integrated with your files, data, and collaborators.

Unified Environment

Your app runs inside a workspace where users already have AI assistant, terminal, file browser, data viewer, project management, and Hub (issues, pull requests, version control, user/group permissions). No need to build these yourself — they are already there.

Collaboration Built In

Every app lives in a Git repository with full version control. Co-authors work together through the Hub: branches, pull requests, code review, and issue tracking. User and group permissions control who can see and edit what. Development with collaborators is as easy as sharing a project link.

Community & Plug-and-Play

Apps follow a plug-and-play plugin model: browse the Apps Catalog, install what you need, uninstall what you don't. Share your tools with the community by publishing to the catalog, or keep them private to your group. Private install lets anyone try an app instantly.

Works Everywhere

SciTeX runs on cloud, self-hosted servers, and local deployments. Apps you build work identically across all environments — develop locally, deploy to your lab's server, or use SciTeX Cloud.

AI-Assisted Development

You don't need to be a web developer. The AI assistant understands the full SciTeX app architecture and can scaffold, code, and debug apps for you. Describe what you need in plain language — in the AI Chat panel or Console terminal — and the AI generates the files, wires up data storage, and handles the technical details. Combined with community-shared apps, even non-technical researchers can customize their workspace with powerful tools.

How It Works

Apps progress through a simple lifecycle:

  1. Create — Scaffold via /new/ page, CLI (scitex-cloud app init), or ask the AI assistant
  2. Develop — Edit templates, views, CSS, and manifest in your project. Hot-reload gives instant feedback.
  3. Install — Install privately for personal use, or submit to the catalog for everyone
  4. Modify — Update your code, push changes, and the app updates automatically
  5. Uninstall — Remove any app cleanly, no side effects

The detailed how-to guides are split by audience:

Detailed Guides

For Users

Browse the Apps Catalog, install and uninstall apps, install privately from Hub Explore, reorder workspace tabs, and star/review apps.

For Creators

File structure, CLI scaffold, templates, views, CSS theming, Platform Services (DataStore, FileVault, JobQueue), AI skill registration, testing, and submission workflow.

For Administrators

PR-based approval workflow, moderation checklist, security scanning, and the scitex/apps registry.
