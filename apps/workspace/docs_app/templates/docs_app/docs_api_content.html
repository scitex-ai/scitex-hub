Web API

REST

Overview

SciTeX Cloud exposes a REST API for integrating with external tools and scripts. All endpoints return JSON and require CSRF token or session authentication.

Base URL: /api/

Authentication

API requests require one of:

Method Header / Cookie
Session Django session cookie (browser login)
CSRF X-CSRFToken header for POST/PUT/DELETE

Module APIs

Each workspace module exposes its own API endpoints:

Module Base Path Key Endpoints
Scholar /scholar/api/ Search, bibliography management, PDF download
Writer /writer/api/ Compile, figure/table management, export
Vis /vis/api/ Plot creation, data upload, figure management
Hub /api/project/ Project CRUD, file browsing, switch project
Console /console/api/ Terminal sessions (WebSocket), SLURM jobs
For the complete API reference with request/response examples, visit the full API documentation.
