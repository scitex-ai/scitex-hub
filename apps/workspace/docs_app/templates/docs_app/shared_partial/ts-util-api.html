API Client

Fetch wrapper with automatic CSRF token injection, JSON serialization, and typed response envelopes.

Import 

import { apiClient, ApiClient, ApiResponse } from '@shared/utils/api';

Usage 

// GET request
const res = await apiClient.get<{ items: string[] }>('/api/items/');
if (res.success) console.log(res.data?.items);

// POST request
const res = await apiClient.post('/api/create/', { name: 'foo' });

// PUT / DELETE
await apiClient.put('/api/items/1/', { name: 'bar' });
await apiClient.delete('/api/items/1/');

// Custom instance with base URL
const client = new ApiClient('/api/v2');
await client.get('/status/');

API Reference

Method / Type Signature Description
apiClient ApiClient Pre-constructed singleton with empty base URL. Use this for all standard requests.
.get() get<T>(url, options?) → Promise<ApiResponse<T>> HTTP GET. CSRF token attached automatically via X-CSRFToken header.
.post() post<T>(url, body?, options?) → Promise<ApiResponse<T>> HTTP POST. body is JSON-serialized automatically.
.put() put<T>(url, body?, options?) → Promise<ApiResponse<T>> HTTP PUT with JSON body serialization.
.patch() patch<T>(url, body?, options?) → Promise<ApiResponse<T>> HTTP PATCH with JSON body serialization.
.delete() delete<T>(url, options?) → Promise<ApiResponse<T>> HTTP DELETE. No body required.
ApiResponse<T> { success: boolean; data?: T; error?: string; message?: string } Unified response envelope. Always check success before accessing data.
CSRF handling: X-CSRFToken is injected on every mutating request via getCsrfToken(). Non-JSON responses (plain text, HTML) are returned as a string in data.
