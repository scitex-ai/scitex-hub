Resizer

Drag-to-resize panels horizontally or vertically, with collapse/expand, magnetic snap, and persistent sizing via localStorage.

Import 

// Auto-initialized from data attributes — no import required.
// For manual use:
import { HorizontalResizer, VerticalResizer, autoInit } from '@shared/components/resizer';

HTML — Horizontal (data-attribute auto-init) 

<!-- Parent must be display:flex (via CSS class) -->
<div class="my-flex-layout">
  <div class="left-panel">...</div>

  <div class="h-resizer"
       data-h-resizer
       data-left=".left-panel"
       data-right=".right-panel"
       data-icon="fa-chevron-left"
       data-title="Files"
       data-most-left
       data-dblclick-toggle
       data-threshold="40"
       data-storage-key="my-app-sidebar"
       data-external-toggle="my-toggle-btn">
  </div>

  <div class="right-panel">...</div>
</div>

HTML — Vertical (data-attribute auto-init) 

<!-- Parent must be display:flex; flex-direction:column (via CSS class) -->
<div class="my-column-layout">
  <div class="top-panel">...</div>

  <div class="v-resizer"
       data-v-resizer
       data-top=".top-panel"
       data-bottom=".bottom-panel"
       data-icon="fa-chevron-up"
       data-title="Output"
       data-most-bottom
       data-dblclick-toggle
       data-threshold="40">
  </div>

  <div class="bottom-panel">...</div>
</div>

Programmatic (TypeScript) 

import { HorizontalResizer } from '@shared/components/resizer';

// Programmatic initialization with callbacks (e.g. Writer editor/preview)
const resizer = new HorizontalResizer(resizerEl, {
  left: ".latex-panel",
  right: ".preview-panel",
  icon: "",            // No toggle button
  title: "Split",
  isMostLeft: false,   // Left panel cannot collapse
  isMostRight: false,  // Right panel cannot collapse
  thresholdPx: 40,
  isInApp: true,       // In-app scoping
  storageKey: "my-app-editor-split",
  onDragStart: () => {
    // Hide iframes/heavy content during drag for performance
    iframe.visibility = "hidden";
  },
  onDragEnd: () => {
    iframe.visibility = "visible";
    pdfViewer?.fitWidth();
  },
});

Data Attributes

Attribute Type Description
data-h-resizer flag Marks element as a horizontal resizer (auto-initialized)
data-v-resizer flag Marks element as a vertical resizer (auto-initialized)
data-left selector CSS selector for the left panel (horizontal only)
data-right selector CSS selector for the right panel (horizontal only)
data-top selector CSS selector for the top panel (vertical only)
data-bottom selector CSS selector for the bottom panel (vertical only)
data-most-left flag Allows the left panel to collapse fully
data-most-right flag Allows the right panel to collapse fully
data-most-top flag Allows the top panel to collapse fully
data-most-bottom flag Allows the bottom panel to collapse fully
data-threshold number Pixel threshold below which panel snaps to collapsed (default: 40)
data-in-app flag Scopes storage key to in-app context (avoids collisions with frame resizers)
data-icon string FontAwesome icon class for the toggle button
data-title string Tooltip title for the toggle button
data-dblclick-toggle flag Enables double-click on resizer handle to toggle collapse/expand
data-storage-key string Custom localStorage key (default: auto-generated from panel selectors)
data-external-toggle string ID of an external button that toggles collapse (e.g. a sidebar toggle in a toolbar)
data-accordion flag When one panel collapses, the other expands fully and the resizer hides
data-snap string Explicit snap points in pixels, comma-separated (e.g. "200,400,600")

Magnetic Snap

Resizers have built-in magnetic snap at percentage-based positions (20%, 25%, 33%, 50%, 67%, 75%, 80% of the container). When dragging near a snap point, the resizer is physically pulled toward it (32px radius, 8px lock zone). A brief green flash on the resizer handle provides visual feedback. Explicit pixel snap points can be added via data-snap.

Gotchas for App Makers

  • flex-basis priority: In flex layouts, flex-basis takes precedence over width/height. The resizer sets both flexBasis and width/height during drag. If your CSS declares flex: 1 1 0%, the flex-basis: 0% will override width — the resizer handles this automatically.
  • Double-init prevention: The data-resizer-initialized attribute prevents re-initialization when multiple Vite bundles load on the same page. If you programmatically create a resizer, the auto-init from data-h-resizer will skip it.
  • iframes during drag: Hide iframes (PDF viewers, embeds) during drag via onDragStart/onDragEnd callbacks. Otherwise the iframe captures mouse events and breaks drag.
  • Two resizer systems: The new system (data-h-resizer / data-v-resizer) in shared/ts/components/resizer/ and the legacy system (data-panel-resizer) in shared/ts/components/_workspace-panel-resizer/ coexist. New apps should use the new system exclusively.
CSS is auto-loaded globally. Resizers re-initialize automatically after HTMX content swaps via htmx:afterSettle. Panel widths/heights are persisted in localStorage per unique panel selector pair.
