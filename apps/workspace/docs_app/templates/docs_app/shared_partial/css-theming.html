CSS Theming System

How light/dark themes and per-module accent colors work in static/shared/css/primitives/colors.css.

Theme Switching

Semantic tokens are remapped by placing data-theme on the <html> element. Components need no changes.

Attribute Effect
:root / [data-theme="light"] Warm neutral grays — eye-friendly, no blue tint. --bg-page: #faf9f7, --text-primary: #333333.
[data-theme="dark"] GitHub Dark-inspired cool tones. --bg-page: #0d1117, --text-primary: #e6edf3.

Module Scoping with data-mode

App modules scope their styles with a [data-mode="yourmodule"] attribute selector to prevent leaking styles into shared panes. 

/* In your module CSS */
[data-mode="mymodule"] .my-panel {
  background: var(--bg-surface);
  border-color: var(--border-default);
}

/* Correct: scoped */
[data-mode="mymodule"] .header { color: var(--text-primary); }

/* Wrong: unscoped — pollutes other modules */
.header { color: var(--text-primary); }

Module Accent Color Pattern

Each registered module has a named accent token. Use it on pane headers and active indicators only.

Token Module Light color Dark color
--module-accent-writer Writer #a07040 #d4a87a
--module-accent-scholar Scholar #3d7a5e #6ba89a
--module-accent-visualizer Visualizer #2e7070 #6ab0b0
--module-accent-console Console #3e6080 #7a9ab8
--module-accent-clew Clew #8a6a4a #b89070
--module-accent-hub Hub #6a5a8a #9a8ab8
--module-accent-docs Docs #4a6a9a N/A
--module-accent-tools Tools #5a7a5a #8ab88a

Each accent also has a -tint variant (e.g. --module-accent-writer-tint) at ~7-8% opacity for subtle panel background tinting. 

/* Apply accent to your module's pane header */
[data-mode="mymodule"] .pane-header {
  border-top: 2px solid var(--module-accent-mymodule);
  background: var(--module-accent-mymodule-tint);
}
The default --module-accent-color and --module-accent-tint are both transparent. Shared panes that serve multiple modules should use the generic token, not a module-specific one.
