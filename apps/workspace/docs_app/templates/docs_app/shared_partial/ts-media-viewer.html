MediaViewer

Displays non-text files (images, PDFs, Mermaid diagrams, binaries) and editable CSV tables in a unified container.

Import 

import {
  MediaViewer,
  detectFileType,
  MediaViewerConfig,
  FileType,
} from '@shared/components/media-viewer';

HTML 

<!-- Container element — MediaViewer renders content inside it -->
<div id="my-media-viewer" class="media-viewer-container"></div>

TypeScript Usage 

const viewer = new MediaViewer({
  container: '#my-media-viewer',
  getFileUrl: (filePath, raw, download) => {
    const params = new URLSearchParams({ path: filePath });
    if (raw) params.set('raw', '1');
    if (download) params.set('download', '1');
    return `/api/files/content/?${params}`;
  },
  onDownload: (filePath) => console.log('Downloading', filePath),
  onVisibilityChange: (visible) => console.log('Viewer visible:', visible),
});

// Open a file — type is auto-detected from extension
viewer.openFile('/project/results/plot.png');

// Check type manually
const type: FileType = detectFileType('/data/report.pdf'); // → 'pdf'

MediaViewerConfig

Option Type Description
container HTMLElement | string Container element or CSS selector
getFileUrl (path, raw?, download?) => string URL factory — called to build fetch/download URLs
onDownload (path) => void Optional callback when user triggers download
onVisibilityChange (visible) => void Optional callback when viewer shows or hides

Supported File Types

FileType Extensions Rendered by
image .png .jpg .jpeg .gif .webp .svg .bmp .ico ImageViewer
pdf .pdf PdfViewer (PDF.js)
csv .csv .tsv CsvEditor (DataTable)
mermaid .mmd .mermaid MermaidViewer
graphviz .dot .gv GraphvizViewer
binary .zip .tar .gz .mp3 .mp4 .docx .xlsx etc. BinaryPlaceholder
text (all others) delegated to text editor
File type is detected automatically by extension via detectFileType(filePath). API responses returning application/json must be parsed; the getFileUrl factory should point to your Django file-content endpoint.
