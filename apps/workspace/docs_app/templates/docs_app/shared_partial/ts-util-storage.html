Storage Manager

Type-safe localStorage wrapper with automatic key prefixing to prevent collisions.

Import 

import { globalStorage, StorageManager } from '@shared/utils/storage';

Usage 

// Save and load (with type inference)
globalStorage.save('sidebar-width', 320);
const width = globalStorage.load<number>('sidebar-width');  // number | null

// Load with a fallback default
const theme = globalStorage.load<string>('theme', 'dark');

// Remove a key or clear all scoped keys
globalStorage.remove('sidebar-width');
globalStorage.clear();  // removes all keys with prefix "scitex_"

// Check existence
if (globalStorage.exists('sidebar-width')) { ... }

// Custom scoped instance (keys stored as "myapp_<key>")
const appStorage = new StorageManager('myapp_');
appStorage.save('state', { open: true });

API Reference

Method Returns Description
globalStorage StorageManager Singleton scoped to prefix "scitex_". Use for all app-level persistence.
.save(key, data) void JSON-serializes data and writes to localStorage under prefix + key.
.load(key, default?) T | null Reads and JSON-parses the stored value. Returns default (or null) on miss or parse error.
.remove(key) void Deletes the entry for the given key (prefix applied automatically).
.clear() void Removes all entries whose storage key starts with this instance's prefix.
.exists(key) boolean Returns true if the key exists in localStorage.
.getAllKeys() string[] Returns all stored keys (with prefix stripped) belonging to this instance's scope.
Prefix namespacing: Every key is stored as prefix + key. The default prefix is "scitex_". Use new StorageManager('myapp_') to create an isolated scope that will not conflict with other modules.
