File Icons

Returns Font Awesome icon HTML strings for file extensions and special filenames, used consistently across all file browsers.

Import 

import { getFileIcon, getFolderIcon } from '@shared/utils/file-icons';

Usage 

// Render a file icon in a list item
const icon = getFileIcon('main.py');
// → '<i class="fab fa-python" style="color: #3776ab; width: 16px; ..."></i>'

listItem.innerHTML = `${icon} ${fileName}`;

// Folder icon
const folderIcon = getFolderIcon();
// → '<i class="fas fa-folder" style="color: #dcb67a; ..."></i>'

// Unknown extension falls back to a generic file icon
const unknown = getFileIcon('archive.xar');
// → '<i class="fas fa-file" style="color: #777; ..."></i>'

API Reference

Function Returns Description
getFileIcon(fileName) string (HTML) Matches on special filenames first (e.g. Dockerfile, Makefile, README.md), then on file extension. Returns an <i> element string with the appropriate Font Awesome class and brand color. Falls back to fas fa-file in grey for unrecognized types.
getFolderIcon() string (HTML) Returns a fixed fas fa-folder icon in #dcb67a (warm gold).
IconConfig { icon: string; color: string } Internal type representing a Font Awesome class name and a CSS hex color string.
