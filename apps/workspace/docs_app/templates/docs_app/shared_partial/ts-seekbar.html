Seekbar

A dual-handle range seekbar for selecting min/max values, with configurable step, format function, hover labels, and drag event callbacks.

Import 

import type {
  SeekbarOptions,
  SeekbarValues,
  FormatFunction,
  ValueCallback,
} from '@shared/components/seekbar/types';

// The seekbar is instantiated via a concrete implementation —
// import from the app that wraps it, e.g.:
import { Seekbar } from '../my-app/seekbar';

HTML 

<!-- Plain container; the seekbar injects its own DOM -->
<div id="my-seekbar"></div>

TypeScript Usage 

const container = document.getElementById('my-seekbar')!;

// Seekbar options
const options: SeekbarOptions = {
  min: 0,
  max: 1000,
  valueMin: 200,
  valueMax: 800,
  step: 1,
  format: (val) => `${val}ms`,
  showLabels: true,
  showValues: true,
  onChange: ({ min, max }) => {
    console.log(`Range: ${min} — ${max}`);
  },
  onUpdate: ({ min, max }) => {
    // called on every drag move
    updatePreview(min, max);
  },
  onStart: ({ min, max }) => console.log('Drag started', min, max),
  onEnd: ({ min, max }) => console.log('Drag ended', min, max),
};

SeekbarOptions

Option Type Default Description
min number 0 Absolute minimum of the range
max number 100 Absolute maximum of the range
valueMin number min Initial position of the lower handle
valueMax number max Initial position of the upper handle
step number 1 Snap increment for handle movement
format (val: number) => string String Label formatter for handle tooltips and value display
showLabels boolean true Show value tooltip above each handle on hover
showValues boolean false Show current min/max values below the track
onChange ValueCallback | null — Called when drag ends with final { min, max }
onUpdate ValueCallback | null — Called on every drag move (throttled)
onStart ValueCallback | null — Called when drag begins
onEnd ValueCallback | null — Called when drag is released
The seekbar renders into a .scitex-seekbar-dual-container element injected inside your container. Both mouse and touch events are supported. The two handles cannot cross each other.
