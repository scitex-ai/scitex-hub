Keyboard Shortcuts

Centralized keyboard shortcut system for workspace pane navigation and AI panel control.

Import 

// The keyboard-shortcuts module is auto-loaded as part of the workspace bundle.
// No explicit import is needed in application code.
import '@shared/components/keyboard-shortcuts';

Built-in Shortcuts 

// These shortcuts are active in all workspace views automatically.

Alt + A              // Toggle AI panel open/closed; focus chat input
Alt + T              // Cycle focus to the next pane (left → right)
Alt + Shift + T      // Cycle focus to the previous pane (right → left)
Alt + Right          // Move focus to the right pane
Alt + Left           // Move focus to the left pane
Alt + Shift + Right  // Collapse the current pane rightward
Alt + Shift + Left   // Collapse the current pane leftward
Ctrl + U             // Open file-upload dialog for AI chat

Pane Discovery

Element / Attribute Role Notes
#scitex-ai-panel AI panel (leftmost pane) Toggle button: #scitex-ai-toggle or #scitex-ai-fab. Collapsed when class collapsed is present.
#main-content Center pane Always visible; never collapsed by shortcut.
[data-panel-resizer] Right-side panels Discovered dynamically via data-panel-resizer attribute. data-target points to the panel element; data-toggle-btn to its collapse button.
.collapsed class Collapse state Pane is treated as collapsed when this class is present. Shortcut skips collapsed panes during focus cycling.
Focus target: When a pane receives focus via keyboard shortcut, the first textarea, input, or [tabindex] element inside it is focused. If none exists, the pane element itself receives focus with tabindex="-1".
Extending shortcuts: The shortcut handler uses a single keydown listener on document. To add application-specific shortcuts without conflicts, listen for keydown on your own component element and call event.stopPropagation() only when your shortcut matches.
