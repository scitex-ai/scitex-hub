Context Zoom

Intercepts Ctrl+Wheel and Ctrl++/-/0 to apply per-pane zoom (font size or CSS scale) based on which pane the mouse is over, with localStorage persistence.

Import 

import {
  initContextZoom,
  registerZoomZone,
  getActiveZone,
  ZoomZone,
} from '@shared/components/context-zoom';

Initialization 

// Call once at app startup — sets up global Ctrl+Wheel listener
initContextZoom();

Register a Zoom Zone 

const editorPane = document.getElementById('my-editor-pane')!;

registerZoomZone({
  el: editorPane,
  storageKey: 'my-app.editor.fontSize',
  min: 10,
  max: 32,
  default: 14,
  step: 1,
  getSize: () => parseFloat(editorPane.style.fontSize) || 14,
  setSize: (val) => { editorPane.style.fontSize = `${val}px`; },
});

// For CSS zoom (scale) instead of font size
registerZoomZone({
  el: previewPane,
  storageKey: 'my-app.preview.zoom',
  min: 0.5,
  max: 3.0,
  default: 1.0,
  step: 0.05,
  getSize: () => parseFloat(previewPane.style.zoom) || 1,
  setSize: (val) => { previewPane.style.zoom = String(val); },
});

// Passthrough: pane handles zoom internally, just block browser zoom.
// Use for components with their own Ctrl+Wheel handler (e.g. Monaco, PDF.js).
// When cursor is over a passthrough zone nested inside a parent zone,
// the parent's CSS zoom is suppressed — only the child's handler fires.
registerZoomZone({
  el: monacoPane,
  storageKey: 'my-app.monaco.zoom',
  min: 0, max: 0, default: 0,
  passthrough: true,
  getSize: () => 0,
  setSize: () => {},
});

// Example: PDF viewer inside #main-content — PDF.js handles its own zoom
registerZoomZone({
  el: pdfViewPane,
  storageKey: 'my-app.pdf.zoom',
  min: 0.5, max: 3.0, default: 1.0,
  passthrough: true,
  getSize: () => 1,
  setSize: () => {},
});

ZoomZone Interface

Field Type Description
el HTMLElement The DOM element defining the zoom zone boundary
storageKey string localStorage key for persisting zoom level
min number Minimum zoom value
max number Maximum zoom value
default number Reset value (Ctrl+0)
step number Increment per scroll tick (default: 1)
getSize () => number Reads current zoom value from the element
setSize (val: number) => void Applies new zoom value to the element
passthrough boolean If true, only blocks browser zoom; element handles zoom itself (e.g. Monaco, PDF.js viewers). Suppresses parent zone's CSS zoom when nested.
Saved zoom values are restored from localStorage on registerZoomZone(). Call initContextZoom() once before registering zones. Zones use mouseenter/mouseleave to track the active zone.

Adding Your Pane

The context-zoom system is initialized globally via context-zoom-init.ts. The central registration auto-discovers panes by ID. To integrate zoom in your pane:

Option 1: CSS Zoom (most apps)

Add your pane's selector to FONT_ZOOM_ZONES in context-zoom-init.ts. Ctrl+Wheel applies CSS zoom to the whole pane uniformly. 

// In context-zoom-init.ts — FONT_ZOOM_ZONES array:
{ selector: "#my-app-pane", key: "my-app-pane-zoom" },
Option 2: Passthrough (components with own zoom)

For components that handle their own Ctrl+Wheel zoom (PDF.js, Monaco, canvas viewers), register as passthrough. This prevents the parent zone's CSS zoom from interfering while letting the component's own handler fire. 

// In context-zoom-init.ts — registerPendingZones():
if (!registeredSelectors.has("#my-canvas-viewer")) {
  const el = document.getElementById("my-canvas-viewer");
  if (el) {
    registerZoomZone({
      el,
      getSize: () => 1,
      setSize: () => {},
      min: 0, max: 0, default: 1,
      storageKey: "my-app-canvas-passthrough",
      passthrough: true,
    });
    registeredSelectors.add("#my-canvas-viewer");
    count++;
  }
}
Nesting: When a passthrough zone is nested inside a CSS zoom zone (e.g. PDF viewer inside #main-content), the inner passthrough zone takes precedence — the parent's CSS zoom is suppressed for that area. Update totalZones when adding new zones.
