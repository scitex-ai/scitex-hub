File Tabs

Manages a row of file tabs with open/close, dirty state indicators, drag-and-drop reorder, inline rename, and an optional new-file button.

Import 

import {
  FileTabManager,
  FileTabsOptions,
  OpenFile,
  TabInfo,
} from '@shared/components/file-tabs';

HTML 

<!-- The manager renders tab elements inside this container -->
<div id="my-file-tabs"></div>

TypeScript Usage 

const tabs = new FileTabManager({
  containerId: 'my-file-tabs',
  onTabSwitch: (filePath) => loadFile(filePath),
  onTabClose: (filePath) => closeFile(filePath),
  onNewFile: async (fileName) => { await createFile(fileName); },
  onRenameFile: async (oldPath, newPath) => { await renameFile(oldPath, newPath); },
  showNewFileButton: true,
  allowReorder: true,
  allowRename: true,
  permanentTab: '*scratch*',
});

// Open a file (adds tab if not already open, activates it)
tabs.openFile('/project/main.py', '# content here', 'python');

// Mark file as dirty (unsaved changes indicator)
tabs.setDirty('/project/main.py', true);

// Close a tab programmatically
tabs.closeTab('/project/main.py');

// Get list of open tabs
const openTabs: TabInfo[] = tabs.getTabs();

FileTabsOptions

Option Type Default Description
containerId string required ID of the container element for tab rendering
onTabSwitch (path) => void required Called when user clicks a tab to activate it
onTabClose (path) => void required Called when user closes a tab
onNewFile (name) => Promise<void> — Called when user creates a new file via the + button
onRenameFile (old, new) => Promise<void> — Called after inline rename completes
showNewFileButton boolean false Show + button to create new files
allowReorder boolean false Enable drag-and-drop tab reordering
allowRename boolean false Enable inline rename on double-click
permanentTab string — Path of a tab that cannot be closed (e.g. *scratch*)
The OpenFile type tracks path, content, originalContent, language, and isDirty. The TabInfo type exposes read-only tab state: path, label, isActive, isDirty, isPermanent.
