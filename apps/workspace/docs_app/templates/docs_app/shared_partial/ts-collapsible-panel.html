Collapsible Panel

A CSS-only collapsible sidebar or properties panel that collapses to 48px and hides content, with smooth width transitions.

Import 

/* CSS is auto-loaded globally — no import needed. */
/* Toggle collapse state in TypeScript: */
panel.classList.toggle('collapsed');

HTML 

<aside class="collapsible-panel">
  <div class="panel-header">
    <h2 class="panel-title">
      <i class="fas fa-cog"></i>
      Settings
    </h2>
    <button class="panel-toggle-btn" onclick="this.closest('.collapsible-panel').classList.toggle('collapsed')">
      <i class="fas fa-chevron-left"></i>
    </button>
  </div>

  <div class="panel-content">
    <!-- your panel body content -->
  </div>

  <div class="panel-footer">
    <!-- optional footer -->
  </div>
</aside>

CSS Classes

Class Element Description
.collapsible-panel <aside> / <div> Root panel wrapper. Apply .collapsed to collapse.
.collapsed modifier on root Shrinks panel to --ui-collapsed-pane-width (default 48px), hides content, makes header vertical
.panel-header child <div> Top bar with title and toggle button (height 50px, flex row)
.panel-title child of header Heading text; when collapsed, shows icon above label at 9px
.panel-toggle-btn child of header Button to toggle collapsed state; compact style when collapsed
.panel-content child <div> Main scrollable body; hidden when collapsed
.panel-body alias Also hidden when collapsed (alternative to .panel-content)
.panel-footer child <div> Optional bottom area; hidden when collapsed

CSS Variables

Variable Default Description
--ui-collapsed-pane-width 48px Width of the panel when collapsed
--ui-nav-icon-size 20px Icon size shown in the collapsed header
Clicking anywhere on a collapsed panel expands it because cursor: pointer is applied to the root. The header layout changes to vertical (icon above label) automatically when .collapsed is present.
