Theme Switcher

Light/dark mode management with localStorage persistence and optional database sync for authenticated users.

Import / Global API 

// No import needed — the module auto-initializes on load.
// Access the global API from anywhere:
window.SciTeX.theme.toggle();
window.SciTeX.theme.set('dark');
const current = window.SciTeX.theme.get(); // 'light' | 'dark'

Usage 

// Toggle button (HTML) — wire it to the built-in handler
<button id="theme-toggle"></button>
// The switcher attaches a click listener automatically on DOMContentLoaded.

// Apply theme programmatically
window.SciTeX.theme.set('light');
window.SciTeX.theme.set('dark');

// Read current theme
const theme = window.SciTeX.theme.get(); // 'light' | 'dark'

// Listen for theme changes (Monaco, xterm, charts)
document.addEventListener('theme-changed', (e) => {
  const { theme } = (e as CustomEvent).detail; // 'light' | 'dark'
  myEditor.updateOptions({ theme: theme === 'dark' ? 'vs-dark' : 'vs-light' });
});

API Reference

API Type / Signature Description
window.SciTeX.theme.toggle() () → void Flips between light and dark; persists choice and dispatches theme-changed event.
window.SciTeX.theme.set(theme) (theme: 'light'|'dark') → void Sets the theme explicitly. Saves to localStorage and syncs to the database for logged-in users.
window.SciTeX.theme.get() () → 'light' | 'dark' Returns the active theme from localStorage. Defaults to 'dark' for new visitors.
data-theme attribute "light" | "dark" on <html> Applied to document.documentElement. CSS variables keyed on this attribute drive all colors.
theme-changed event CustomEvent<{ theme: 'light'|'dark' }> Dispatched on document after every theme change. Listen here to update third-party components.
#theme-toggle button HTML element If present in DOM, the switcher attaches a click handler and updates button content automatically.
Auto-init: The module calls initTheme() immediately on import — before DOM ready — to prevent a flash of the wrong theme. For authenticated users it fetches the preference from /auth/api/get-theme/ and syncs it to localStorage.
