Layout Utility Classes

Atomic helper classes from static/shared/css/utilities/utils/ — globally available on every page via common.css.

Spacing Utilities (01-spacing.css)

Follow the pattern {property}{side}-{scale}. Scale maps to spacing variables.

Scale Variable Value
1 --spacing-xs 0.25rem
2 --spacing-sm 0.5rem
3 --spacing-md 0.75rem
4 --spacing-lg 1rem
5 --spacing-xl 1.5rem
6 --spacing-xxl 2rem
8 / 10 / 12 — 2.5 / 3 / 4rem

Available prefixes: m (margin), p (padding). Available sides: t top, b bottom, l left, r right, x horizontal, y vertical, or omit for all sides. Special: mx-auto, ml-auto, mr-auto. 

<div class="mt-4 mb-2 px-3">Spaced content</div>
<div class="mx-auto p-5">Centered with padding</div>

Display Utilities (02-display.css)

Class CSS property
.block display: block
.inline-block display: inline-block
.inline display: inline
.flex display: flex
.inline-flex display: inline-flex
.grid display: grid
.hidden display: none

Category Classes

Flex sizing .flex-1 .flex-auto .flex-none .flex-grow .flex-shrink .flex-shrink-0
Gap .gap-0 through .gap-8 (maps to spacing scale)

  <span class="flex-1">Label</span>
  <button class="flex-shrink-0">Action</button>
</div>
