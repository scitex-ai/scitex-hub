Web-Based Creation (/new/)

You can also create apps directly from the browser at /new/. The creation page offers several project types:

Type Description
App Template Scaffolds a complete app with manifest, views, templates, CSS, skill, and tests — same output as scitex-cloud app init
Project Template Clone from templates provided by the scitex Python package (research_minimal, pip_project, paper_directory, etc.)
Empty / Git Clone / GitHub Import Start from scratch, clone an existing repo, or import from GitHub

When you select App Template, the platform calls scitex_cloud.appmaker.init_app() to generate the full boilerplate, creates a Gitea repository, and initializes the project — all in one step.

AI-Assisted Creation

AI agents in the AI Chat panel and the Console terminal already have knowledge of the entire SciTeX app architecture. You can ask the AI to:

  • Scaffold a new app end-to-end (file structure, registry, URLs, tests)
  • Explain any concept on this page interactively
  • Generate manifest schemas for your data models
  • Wire up Platform Services (DataStore, JobQueue, etc.)
  • Create CSS theming with the correct variable names
  • Debug validation errors before submission

This works because each module registers a Skill that feeds domain knowledge to the AI. The platform skill is auto-generated from all apps/*/skill.py registrations and deployed on every terminal connect.

Try it: Open the Console terminal and ask “Create a new workspace app called sample_tracker_app with a DataStore for samples” — the AI will scaffold the entire app structure for you.
