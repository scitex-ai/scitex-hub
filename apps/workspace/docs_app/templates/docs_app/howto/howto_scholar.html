{% trans "How to use Scholar" %}

{% trans "Scholar is where you look for papers and keep your reference library." %}

{% trans "Steps" %}

  1. {% blocktrans trimmed %} Open Scholar from Home. It has three tabs: Search databases, Library and Citation Graph. {% endblocktrans %}
  2. {% blocktrans trimmed %} Click the ? button in the search box to see the search operators, for example -a Smith for an author or -ymin 2020 for papers from 2020 on. Click an operator to insert it. {% endblocktrans %}
  3. {% blocktrans trimmed %} Use the Sources, Sorters and Filters panels on the right to choose which databases to search and how to order the results. {% endblocktrans %}
  4. {% blocktrans trimmed %} Open the Library tab. It lists the papers you have saved, with a search box and a sort menu. {% endblocktrans %}
  5. {% blocktrans trimmed %} Open the BibTeX / RIS panel on the right of the Library. It holds Import BibTeX (.bib) and the BibTeX and RIS export buttons. {% endblocktrans %}

{% trans "Tips" %}

  • {% trans "Press Ctrl+K to jump to the search box." %}
  • {% trans "Put a minus sign in front of a word to exclude it, for example -t -mouse." %}

{% trans "Troubleshooting" %}

  • {% trans "No results found: check the spelling, try more general keywords, or remove filters such as -ymin." %}
  • {% trans "Search seems down: open the Service Status panel on the Library tab." %}
