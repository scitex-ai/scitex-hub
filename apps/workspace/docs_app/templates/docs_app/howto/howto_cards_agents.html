{% trans "What are Cards and Agents?" %}

{% trans "Cards are tasks. Agents are AI assistants that can work on your projects. Both apps are on Home." %}

{% trans "Steps" %}

  1. {% blocktrans trimmed %} On Home, find Cards and Agents in the Foundation group, next to My Projects. {% endblocktrans %}
  2. {% blocktrans trimmed %} Open Cards. A card is one task: what to do, who owns it and its status. People and AI agents use the same cards to keep track of work. {% endblocktrans %}
  3. {% blocktrans trimmed %} Your own cards are listed on this page. Until you have some, it says Your own cards will appear here. Nothing from other people is shown on it. {% endblocktrans %}
  4. {% blocktrans trimmed %} Open Agents. An agent is an AI assistant that runs on its own and works on tasks. Your agents will be listed here; until then the page says Your own agents will appear here. {% endblocktrans %}
  5. {% url 'pane-chat' as chat_url %} {% blocktrans trimmed %} To talk to an AI assistant today, use Chat. To connect your own AI agent, such as Claude Code, read the MCP Tools pages in this documentation. {% endblocktrans %}

{% trans "Tips" %}

  • {% trans "Back to Home on the Cards or Agents page returns you to your apps." %}
  • {% trans "See How to use Chat for connecting an AI provider." %}

{% trans "Troubleshooting" %}

  • {% trans "The page takes a while to open: wait a few seconds, then reload if it stays blank." %}
  • {% trans "You expected to see a teammate's cards: this page shows only your own cards." %}
