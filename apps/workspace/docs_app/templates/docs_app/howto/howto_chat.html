{% trans "How to use Chat" %}

{% trans "Chat lets you ask an AI assistant about your research and your projects." %}

{% trans "Steps" %}

  1. {% blocktrans trimmed %} Open Chat from Home or from the dock at the bottom of the page. {% endblocktrans %}
  2. {% blocktrans trimmed %} Type your request and press Enter. Name the project you mean, for example "Summarize the README of my project sleep-memory-study". If you see No AI provider configured, connect a provider first. {% endblocktrans %}
  3. {% url 'accounts_app:ai_providers' as ai_providers_url %} {% blocktrans trimmed %} Go to Settings > AI providers and open Add a new provider. Choose a provider, paste your API key and click Add provider. {% endblocktrans %}
  4. {% blocktrans trimmed %} Return to Chat and send your request again. {% endblocktrans %}
  5. {% blocktrans trimmed %} Click + to start a new chat. Each chat has its own tab, and the buttons on the right copy, print, clear or share the conversation. {% endblocktrans %}

{% trans "Tips" %}

  • {% trans "Your API key is encrypted at rest. Leave Default Model blank to use the provider's default." %}
  • {% trans "The Write, Analyze, Code and Literature buttons under the input box start a request of that kind." %}

{% trans "Troubleshooting" %}

  • {% trans "No AI provider configured: add a provider in Settings > AI providers, then send the message again." %}
  • {% trans "To see how much you have used, open Settings > AI usage." %}
