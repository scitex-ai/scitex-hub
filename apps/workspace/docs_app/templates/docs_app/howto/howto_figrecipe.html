{% trans "How to use FigRecipe" %}

{% trans "FigRecipe makes publication-ready figures and exports them as PNG, SVG or PDF." %}

{% trans "Steps" %}

  1. {% blocktrans trimmed %} Open FigRecipe from Home. It opens with a demo figure in the middle. {% endblocktrans %}
  2. {% blocktrans trimmed %} Pick a plot type in the left rail, for example Line, Scatter or Bar. A gallery of templates for that type opens. {% endblocktrans %}
  3. {% blocktrans trimmed %} Click a template. The plot appears in the viewer, and the number under the rail counts the plots in your figure. {% endblocktrans %}
  4. {% blocktrans trimmed %} Click Export, type a file name and choose PNG (300 DPI), SVG or PDF. {% endblocktrans %}
  5. {% blocktrans trimmed %} Click the export button at the bottom of the dialog. The figure file downloads to your computer. {% endblocktrans %}

{% trans "Tips" %}

  • {% trans "Choose SVG or PDF when a journal asks for vector figures." %}
  • {% trans "The demo figure comes from demo_first_figure.yaml in your first project, so you can open that recipe again later." %}

{% trans "Troubleshooting" %}

  • {% trans "The template gallery covers the figure: close it with the X button in its corner." %}
  • {% trans "Nothing downloads: check that your browser allows downloads from this site." %}
