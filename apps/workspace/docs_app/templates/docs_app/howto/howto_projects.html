{% trans "How to use Projects" %}

{% trans "A project is a folder for one piece of research. Create one, then browse its files." %}

{% trans "Steps" %}

  1. {% blocktrans trimmed %} Sign in. Home shows your apps. My Projects lists the projects you own. {% endblocktrans %}
  2. {% url 'project_create' as new_project_url %} {% blocktrans trimmed %} Open Create new project. Keep SciTeX Minimal selected, type a name and, if you like, a description. {% endblocktrans %}
  3. {% blocktrans trimmed %} Click Create project. The project opens with its file tree on the left. A new project starts with README.md and LICENSE. {% endblocktrans %}
  4. {% blocktrans trimmed %} Click a file in the tree to open it in the Viewer. {% endblocktrans %}
  5. {% blocktrans trimmed %} Click the Repository view icon above the tree. It lists every file with its last commit, and has tabs for Issues, Pull requests and Settings. {% endblocktrans %}

{% trans "Tips" %}

  • {% trans "Use lowercase letters and hyphens in project names, for example sleep-memory-study." %}
  • {% trans "Every project is a Git repository. The repository view shows its branches and commits." %}
  • {% trans "Scholar and Writer keep their files inside the project, in the hidden .scitex folder." %}

{% trans "Troubleshooting" %}

  • {% trans "A project looks empty in the tree: click the small arrow next to its name to expand it." %}
  • {% trans "You cannot find the manuscript folders: open the repository view, where the hidden .scitex folder is listed." %}
