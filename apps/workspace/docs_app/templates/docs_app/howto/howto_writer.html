{% trans "How to use Writer" %}

{% trans "Writer is a LaTeX editor for your manuscript, with a live PDF preview." %}

{% trans "Steps" %}

  1. {% blocktrans trimmed %} Open Writer from Home. The editor is on the left, the PDF in the middle and the Details panel on the right. {% endblocktrans %}
  2. {% blocktrans trimmed %} Pick a document (Manuscript, Supplementary, Revision or Shared) in the first menu, then a section such as Abstract or Methods in the section menu. {% endblocktrans %}
  3. {% blocktrans trimmed %} Type your text in the editor. Your changes are saved, and the word count above the editor updates as you write. {% endblocktrans %}
  4. {% blocktrans trimmed %} In Details, open Compilation - Preview and click Compile Preview. When the log says the compilation completed, the PDF of the section appears. Tick Compile on Change to recompile as you type. {% endblocktrans %}
  5. {% blocktrans trimmed %} Click the download icon above the PDF to save the compiled PDF. {% endblocktrans %}

{% trans "Tips" %}

  • {% trans "Writer opens the manuscript of your current project. Project Info in the Details panel shows which project that is." %}
  • {% trans "Use the font size menu and the moon icon above the editor to make writing comfortable." %}

{% trans "Troubleshooting" %}

  • {% trans "Compilation Error with 'Unicode character ... not set up for use with LaTeX': the section contains a character LaTeX cannot print, often a full-width symbol. Delete it and compile again." %}
  • {% trans "The PDF does not change: click Compile Preview again and read the last lines of the log." %}
