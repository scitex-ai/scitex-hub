How to Use Clew

Forward: Track

Use @scitex.session and scitex.io in your scripts. Clew automatically records inputs, outputs, and hashes. 

import scitex
@scitex.session
def main():
    data = scitex.io.load("input.csv")

Backward: Verify

Select any artifact to trace its full dependency chain back to source data as a DAG. 

scitex clew chain output.png
scitex clew status
scitex clew list
