How to Use Clew

Forward: Track

Use @stx.session and stx.io in your scripts. Clew automatically records inputs, outputs, and hashes. 

@stx.session
def main():
    data = stx.io.load("input.csv")
    stx.io.save(result, "output.png")

Backward: Verify

Select any artifact to trace its full dependency chain back to source data as a DAG. 

scitex clew chain output.png
scitex clew status
scitex clew list

Click Add Examples to get started, then run ./examples/clew/00_run_all.sh in the terminal.
