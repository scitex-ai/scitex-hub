Keyboard Shortcuts

Global Shortcuts (Always Active)

Alt+F Files Alt+S Scholar Alt+C Console Alt+V Visualizer Alt+W Writer Alt+Z Zen Mode F11 Cycle Zen/Fullscreen

Canvas

+ / - Zoom in/out
0 Fit to window
Ctrl+0 Reset canvas size
G / Space Toggle grid
Delete Delete selected
Ctrl+D Duplicate selected
Ctrl+A Select all
Escape Deselect / Exit mode
Arrow keys Nudge selected
Shift+Arrow Resize selected

Copy/Paste

Ctrl+C Copy object
Ctrl+V Paste object
Ctrl+Shift+C Copy view (axis limits)
Ctrl+Shift+V Paste view
Ctrl+Z Undo
Ctrl+Y Redo

Alignment (Alt+A then...)

L Align left
R Align right
T Align top
B Align bottom
C Center horizontally
M Center vertically
H Distribute horizontal
V Distribute vertical

Arrange & Group

Alt+F Bring to front
Alt+B Send to back
Ctrl+G Group selection
Ctrl+Shift+G Ungroup

Size Mode (Alt+Z then...)

S Match size
W Match width
T Match height
C Multiple crop
