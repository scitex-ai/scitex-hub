How to Contribute

Use it and report issues

Deploy SciTeX, try it with your workflow, tell us what breaks or what's missing.

Code contributions

Fix bugs, add features, improve performance. The codebase is on GitHub under AGPL-3.0.

Documentation

Write tutorials, improve API docs, explain concepts. Good docs lower the barrier to entry.

Design and UX

Help make the interface clearer and more intuitive. Researchers shouldn't need a manual.

Domain expertise

Tell us what your field needs. Different disciplines have different workflows and requirements.

Spread the word

If you find SciTeX useful, tell colleagues. Open source grows through word of mouth.
