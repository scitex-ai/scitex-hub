How to Use

  1. Drag the button above to your bookmarks bar
  2. Navigate to any website you want to inspect
  3. Click the bookmark OR press Alt+I
  4. Click any element to copy its debug info to clipboard
  5. OR press Ctrl+Alt+I for selection mode (drag to select area)
  6. Press Escape to close when done

What Gets Copied

Single Element Mode (Click):

  • Element tag, ID, classes, and CSS selector
  • All HTML attributes (href, src, data-*, aria-*, etc.)
  • Computed CSS styles (display, position, colors, fonts, etc.)
  • Dimensions and position on page
  • Text content preview (first 200 characters)

Selection Mode (Ctrl+Alt+I + Drag):

  • All elements within selected area
  • Hierarchical structure showing parent-child relationships
  • Debug info for each element in the selection
