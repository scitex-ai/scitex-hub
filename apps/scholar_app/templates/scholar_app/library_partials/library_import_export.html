Prism does not currently offer a public API for programmatic migration. Use the following workflows to transfer your work.

  1. In Prism, export your project as a ZIP file (LaTeX project)
  2. Use Overleaf Import to import the ZIP into SciTeX
  3. Or export BibTeX from Prism and use Zotero Import
  1. Use Overleaf Export to download your project as a ZIP
