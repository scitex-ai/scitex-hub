# SLURM Configuration for SciTeX Cloud

## Partition Time Limits

The partition time limits are configured to match the application's resource quotas defined in `.env.prod`:

```bash
# Interactive Terminal Sessions (express partition)
SCITEX_QUOTA_SLURM_INTERACTIVE_TIME_LIMIT=04:00:00  # 4 hours
SCITEX_QUOTA_SLURM_INTERACTIVE_PARTITION=express

# Batch Job Limits (normal/long partitions)
SCITEX_QUOTA_SLURM_MAX_RUNTIME_HOURS=32  # 32 hours
```

### Partition Configuration

| Partition | MaxTime | Purpose |
|-----------|---------|---------|
| `normal` | 24:00:00 | Default partition for batch jobs (1 day) |
| `express` | **04:00:00** | Interactive terminals - must match `SCITEX_QUOTA_SLURM_INTERACTIVE_TIME_LIMIT` |
| `long` | 7-00:00:00 | Long-running batch jobs (7 days) |

## Why 4 Hours for Express?

The `express` partition is used for **interactive terminal sessions** via the Code Workspace. The 4-hour limit balances:

1. **User Experience**: Enough time for interactive development sessions
2. **Resource Fairness**: Prevents terminals from hogging resources indefinitely
3. **Batch Job Priority**: Encourages users to submit long-running tasks as batch jobs

## Configuration Files

1. **Host**: `/etc/slurm/slurm.conf` - Generated by `install-host.sh`
2. **Docker (prod)**: `deployment/slurm/slurm-docker-prod.conf` - Used by Django container
3. **Docker (Dev)**: `deployment/slurm/slurm-docker-dev.conf` - Used for local development

## Changing Time Limits

To change the interactive terminal time limit:

1. Update `.env.prod`:
   ```bash
   SCITEX_QUOTA_SLURM_INTERACTIVE_TIME_LIMIT=02:00:00  # Example: 2 hours
   ```

2. Update SLURM partition config:
   ```bash
   # Edit /etc/slurm/slurm.conf
   PartitionName=express Nodes=... MaxTime=02:00:00 ...

   # Reload SLURM
   sudo scontrol reconfigure
   ```

3. Restart Django container:
   ```bash
   docker restart scitex-cloud-prod-django-1
   ```

## Troubleshooting

### Jobs Stuck with "PartitionTimeLimit"

This means the requested time exceeds the partition's MaxTime:

```bash
# Check partition limits
scontrol show partition express | grep MaxTime

# Check job details
scontrol show job <JOBID>

# Fix: Either reduce job time or increase partition MaxTime
```

### After Reinstalling SLURM

The `install-host.sh` script automatically sets MaxTime=04:00:00 for the express partition. If you manually changed this, you'll need to update the script before reinstalling.
