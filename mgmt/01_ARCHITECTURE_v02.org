# Subject: scitex.vis Directory-Based Figure Storage Architecture

* Project Overview

** Objective
Implement directory-based figure storage for scitex.vis:
- Path: `project/scitex/vis/figures/{fig_descriptive_name}/`
- Each figure directory contains: `figure.json`, `data/`, `exports/`
- 1 Canvas = 1 Figure = 1 Directory

** Design Principles
1. scitex-code package: Core logic + simple APIs (NO Django dependencies)
2. scitex-cloud (Django): Thin wrapper over scitex-code APIs
3. NO backward compatibility: Clean slate, no legacy support
4. Project-centric: All operations link to user/group projects
5. Data integrity: Hash-based verification for all data files
6. Descriptive naming: `fig_descriptive_name` used as figure ID (also in writer)

#+BEGIN_SRC python
# apps/vis_app/views.py

import scitex as stx

def list_figures(request, project_id):
    """List all figures in project."""
    project_path = get_project_path(project_id)
    figures = stx.vis.io.list_figure_directories(project_path)
    return JsonResponse({"figures": figures})

def get_figure(request, project_id, fig_name):
    """Get figure JSON."""
    project_path = get_project_path(project_id)
    fig_json = stx.vis.io.load_figure_json(project_path, fig_name)
    return JsonResponse(fig_json)

def create_figure(request, project_id, fig_name):
    """Create new figure directory."""
    project_path = get_project_path(project_id)
    fig_dir = stx.vis.io.ensure_figure_directory(project_path, fig_name)
    return JsonResponse({"path": str(fig_dir)})

def save_figure(request, project_id, fig_name):
    """Save figure JSON."""
    project_path = get_project_path(project_id)
    fig_json = json.loads(request.body)
    stx.vis.io.save_figure_json(project_path, fig_name, fig_json)
    return JsonResponse({"success": True})

def delete_figure(request, project_id, fig_name):
    """Delete figure directory."""
    project_path = get_project_path(project_id)
    success = stx.vis.io.delete_figure_directory(project_path, fig_name)
    return JsonResponse({"success": success})

def export_figure(request, project_id, fig_name, format):
    """Export figure to format."""
    project_path = get_project_path(project_id)
    export_path = stx.vis.io.export_figure_to_file(project_path, fig_name, format)
    return FileResponse(open(export_path, 'rb'))

** Key Differences

| Aspect | stx.plt | scitex.vis |
|--------|---------|------------|
| Scope | Multiple figures in one dir | One figure per directory |
| Organization | By file type or flat | By purpose (data, exports) |
| Use case | Batch plotting output | Interactive canvas editing |
| Data integrity | None | SHA256 hash verification |

* Summary

| Aspect | Decision |
|--------|----------|
| Directory path | `project/scitex/vis/figures/{fig_descriptive_name}/` |
| Naming | Descriptive names (e.g., `neural_activity`, `connectivity_matrix`) |
| Data references | Relative paths (`data/trace.csv`) with SHA256 hash |
| Hash verification | On load by default, can disable |
| Export structure | Flat (`exports/figure.png`, `exports/figure.pdf`) |
| Manual overrides | Stored in `figure.json` under `manual_overrides` key |
| Backward compat | None - clean implementation |
